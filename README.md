# チョイソコひの 利用状況ダッシュボード

滋賀県日野町の予約制の乗合交通「チョイソコひの」について、町が公開している利用状況レポート（PDF）の数値を CSV に転記し、グラフと表にしたページです（非公式の試作）。

`index.html` と `data/` の CSV だけで動きます。作り直しの手順はありません。

公開URL：`https://kken78.github.io/choisoko-hino-dashboard/`

## 画面の構成

1. 集計時点の切り替え

   利用状況レポートは、運行開始（令和5年3月）からの累計で発行されています。令和5年3月末（初月）・令和6年3月末・令和7年3月末・令和8年3月末・令和8年6月末・令和8年9月末の6時点を上部の切り替えで選び、その時点の登録会員数・利用会員数・年代別構成などを表示します。指標の札では、一つ前の時点の値と、比べた時点・期間を書きます（数え方の違う値は比べません）。

2. 月ごとの推移

   利用件数・1日当たり利用件数・月別利用人数を、運行開始からの全月で表示します。令和5年3月から9月は運賃無料、令和5年10月から有償運行です。利用件数の推移には、運行エリアの拡大などの出来事の印（6つ）を置き、図の下の表に時期・出来事・出典（広報ひの、記者発表資料）を書きます。

3. 会員の構成、時間帯・曜日・予約、目的地、地区

   年代別・男女別の会員の構成、時間帯別の利用割合（時点 × 時間帯の表）、曜日別の平均利用件数、予約の時期と方法、目的地停留所の乗降回数（上位15）、地区別の利用状況を収録しています。令和8年9月末までの累計では、時間帯別の利用割合は9時台が 15% で最も多く、8時台と10時台が 13% です。利用会員の年代は80歳代が 26% で最も多く、利用会員の男女の内訳は男性 309人・女性 655人です。

4. 外部サイトへの埋め込み

   URL の末尾に `?embed=true` を付けると、見出し・フッターが表示されません。`#trend` などで開く位置を指定できます。

   ```html
   <iframe
       src="https://kken78.github.io/choisoko-hino-dashboard/?embed=true#trend"
       width="100%" height="520" style="border:none;background:transparent;">
   </iframe>
   ```

5. 幅の狭い画面と操作

   幅の狭い画面では1列で表示します。キーボードで操作したときにフォーカスの位置を表示し、`prefers-reduced-motion` の設定では動きを止めます。

## ローカルでの確認

CSV を `fetch` で読み込むため、ファイルを直接開くのではなく簡易サーバ経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 共通の部品

`index.html` の見出し・分野のナビ・ページの一覧・フッターと、その CSS（`<!-- portal-shared:〈名前〉 start/end -->` で囲んだ箇所）は、[hino-portal](https://github.com/kken78/hino-portal) の `shared/` の正本の写し（DESIGN.md ADR-1）。手元では、正本と同じかと文字の大きさ（hino-portal DESIGN.md 5.2、DESIGN.md ADR-3）を `python3 <hino-portal>/shared/check.py --fonts index.html` で、幅 360px と 1024px での文字の実寸と横のはみ出しを `node <hino-portal>/shared/check_mobile.mjs index.html`（Playwright が要る。置き方は hino-portal の shared/README.md）で確かめる（CI の `.github/workflows/check-shared.yml` でも同じ検査を行う）。

## 免責事項

- 本リポジトリの CSV は公開 PDF から独自に抽出したものです。読み取り誤差や変換ミスを含む可能性があるため、正確な数値が必要な場合は必ず日野町の公式資料をご確認ください。
- 一部の月別利用人数・年代別構成は、原資料でのラベル・数値の重なりにより読み取りに幅があります。とくに `monthly.csv` の 2025-05（R7.5）の月別利用人数は、原資料でデータラベルが隣のラベルに完全に隠れているため、棒の高さから推定した値（162 ≒ ±1）です。
- R8.6 版報告書の記載に合わせ、2025-05〜2026-01 の月別利用人数を修正しました（旧版からの読み取り時にラベルと棒の対応がずれていたため）。
- 2026-06（R8.6）の利用件数・1日当たり件数は、R8.6 版の 1,544 件・70.1 件/日 から、R8.9 版の記載に合わせて 1,554 件・70.6 件/日 に更新しました。
- 2025-02（R7.2）と 2025-03（R7.3）の月別利用人数は取り違えていたため、R7.3 版の記載どおり 129 人・128 人に修正しました。
- 2026-04（R8.4）の月別利用人数は、原資料でラベル末尾が隠れています（「24」までは判読可）。隠れた数字の下部の形と棒の高さから推定した値（240）です。
- R8.6・R8.9 の累計サマリーのうち「利用人数」「1日当たり利用件数」「1日当たり利用人数」「路線数」は報告書に記載がないため空欄です。
- R8.6・R8.9 の `summary.csv` の「利用件数」は、報告書の地区別表の「予約件数」合計（R8.9: 30,855 件）です。月別利用件数の合計（R8.9 時点で 30,962 件）とは一致しません。
- R8.9 版の利用会員の男女内訳（男性 309 人・女性 655 人、計 964 人）は、同じ資料の利用会員数（1,009 人）と一致しません。原資料の記載のまま収録しています。
- 乗合率には原資料に注記があり、R5.3・R6.3 は「3月中」、R7.3 以降は「月中」です。画面の指標の札では、注記の違う時点どうしの増減を出していません。
- 2023-09（R5.9）の運行区分を「有償」から「無償」に直しました（2026-11-08）。利用状況レポート（令和6年3月末まで）p.2 の図では3月〜9月が無償運行、10月〜3月が有償運行で、広報ひの 2023年9月号 p.11 にも「10月からは運賃を有料として」とあります。
- このページは日野町の公式のサイトではなく、個人が作成した試作です。予告なく内容を変えたり、公開をやめたりすることがあります。

## 町のページの巡回

毎月1日の朝（JST）に、GitHub Actions（`.github/workflows/watch.yml`）が町の「チョイソコひの」のページを巡回し、見つけたものを Issue にします。道具は `tools/watch.py`（標準ライブラリだけ。取得は1秒に1件以内）、見るページは `data/watch.json`、知っている資料とページの更新日は `data/watch.tsv` です。

| 見つけるもの | 確かめ方 |
|---|---|
| 新しい資料 | 見るページに、`data/watch.tsv` に無い PDF のリンクがある |
| 資料が取れない | `data/watch.tsv` で status が「使用」の PDF（利用状況レポート（5時点。令和8年6月末はWebアーカイブの保存版））が、ページからリンクされなくなったか、404 などで取れない |
| ページの更新 | ページの「更新日」が `data/watch.tsv` の updated と違う |

巡回は見つけるだけで、`data/` のデータと画面は変えません。Issue の本文の「次にやること」に従って転記し、`data/watch.tsv` に行を足すか updated を直します（直さないと次の月にまた Issue ができます）。巡回そのものに失敗したときは、ワークフローが失敗して「巡回に失敗した」Issue ができます。同じ内容の Issue が開いていれば作りません。手元では `python3 tools/watch.py` で確かめられます。定期実行は60日間コミットが無いと止まるため、`.github/workflows/keepalive.yml` が毎月1日に有効化し直します。
